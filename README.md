# Steam & Steel — launcher and modpack downloads

Steam & Steel is a Minecraft Java 1.21.1 server built around Create, Aeronautics and TFMG. This repository distributes signed Windows launcher updates and the supported installation archives.

## English

- [Official server website](https://steamsteel.minecraft.best/) — the project and getting started.
- [Server facts and installation guide](https://steamsteel.minecraft.best/facts-en.html) — the modpack, Java setup, PC requirements and troubleshooting.
- [Launcher, supported MRPACK and manual ZIP](https://fjwhcjwhgcdyuguh.github.io/steamsteel-launcher-updates/?lang=en) — choose the installation route for your launcher.
- [Six-ring world map](https://steamsteel.minecraft.best/world-en.html) — resources, climate and progression zones.
- [Gameplay mod catalogue](https://steamsteel.minecraft.best/mods-en.html) — the main mods and the project's custom modules.
- [Discord](https://discord.gg/4Pjt9FRq37) — current rules and installation help.

For another launcher, import the supported MRPACK or follow the manual ZIP README. The native bootstrap uses Minecraft 1.21.1, NeoForge 21.1.235 and Java 21 x64. Add the required Java argument from the included README before launching; on Windows, Show-Java-Argument.cmd displays the complete argument. AutoModpack downloads the gameplay pack when you connect to steamsteel.minecraft.best and updates it on later connections.

Provisional starting profile without shaders: 16 GB computer RAM, start with 6 GB allocated to the game (up to 8 GB with sufficient headroom), and 20 GB free SSD space. These are recommendations, not measured minima or an FPS guarantee.

The [CurseForge starter](https://www.curseforge.com/minecraft/modpacks/steam-steel-smp) 2026.11.09-bootstrap.1 is a separate Beta artifact and does not contain the required native compatibility component. Follow the supported website installation guide. Archive structure checks do not establish a successful fresh multiplayer installation.
